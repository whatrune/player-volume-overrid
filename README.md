# player-volume-override

## ■ 概要

FiveM（pma-voice環境向け）の、**プレイヤー別・ローカル音量調整**リソースです。  
このリソースを使うと、特定プレイヤーの近接VC音量を **自分のクライアント上だけ** で調整できます。

- ✅ 自分だけに反映（他プレイヤーには影響しない）
- ✅ `license` ベース保存（再ログインでIDが変わっても再適用）
- ✅ チャットコマンドで操作（`/pv`, `/pvreset`, `/pvlist`, `/pvmute`）

`player-volume-override` は、近接VCの聞こえ方を **プレイヤーごとに調整**するための補助リソースです。  
操作は現在の **サーバーID**（例: `12`）で行いますが、内部では安定した識別子である **`license:`** に紐づけて保存します。  

対象プレイヤーが再接続してサーバーIDが変わっても、同じプレイヤーであれば設定が自動で再適用されます。  

---

## ■ 注意事項（重要）

このリソースは FiveM の **Mumble 音量 override native** を使用しています。

その仕様上、対象プレイヤーの音声は通常の近接VCと比べて、  
**距離による減衰（3D/距離感）** が少し自然でなくなる場合があります。

### 推奨用途

このリソースは**「少し声が大きい／小さい人を微調整する」** 用として使うのがおすすめです。

---

## ■ 音量の範囲（重要）

`/pv` で指定できる範囲は以下です。

- **0.1 = 小さい（静かめ）**
- **0.9 = 大きい（大きめ）**

### 値の目安

- `0.1` → かなり小さい（ほぼミュート寄り）
- `0.5` → 中くらい
- `0.8` → 大きめ
- `0.9` → `/pv` で設定できる最大値

> `/pvmute` は `0.0`（ミュート）を使用します。

---

## ■ コマンド一覧

### `/pv [serverId] [volume]`

指定プレイヤーの音量を設定します。

**使い方）**
```text
/pv [serverId] [0.1~0.9]
```

**例）**
```text
/pv 12 0.8
```

この例では、**ID 12** のプレイヤーの声を、自分のクライアント上で大きめに設定します。

---

### `/pvreset [serverId]`

指定プレイヤーの音量設定を解除し、デフォルトに戻します。

**使い方）**
```text
/pvreset [serverId]
```

**例）**
```text
/pvreset 12
```

---

### `/pvlist`

保存済みのプレイヤー別音量設定一覧を表示します。

**使い方）**
```text
/pvlist
```

### 表示形式

- オンライン中: `ID 12 (PlayerName) => 0.80`
- オフライン: `Offline ...license末尾 => 0.80`

---

### `/pvmute [serverId]`

指定プレイヤーをローカルでミュートします（音量 `0.0`）。

**使い方）**
```text
/pvmute [serverId]
```

**例）**
```text
/pvmute 12
```

ミュート解除は以下を使ってください。

```text
/pvreset 12
```

---

## ■ 動作の仕組み

### 1) サーバーIDで指定

コマンドでは、その時点のサーバーID（例: `12`）を指定します。

### 2) 内部で `license` に変換

リソース内部で `serverId -> license` に変換して扱います。

### 3) ローカル保存

音量設定は、クライアント側の KVP に **licenseベース** で保存されます。

### 4) 自動再適用

対象プレイヤーが再接続してサーバーIDが変わっても、一定間隔でプレイヤーマップを更新し、自動で再適用します。

---

## ■ 導入方法

リソースを以下に配置してください。

```text
resources/[voice]/player-volume-override
```

### 必要ファイル

- `fxmanifest.lua`
- `client.lua`
- `server.lua`

### server.cfg に追加

```cfg
ensure player-volume-override
```

### 読み込み / 再読み込み

txAdmin コンソール（またはサーバーコンソール）で実行:

```text
refresh
ensure player-volume-override
```

---

## ■ 依存関係

- FiveM サーバー
- `chat` リソース（チャット通知表示に使用）
- pma-voice 環境（近接VC運用前提として推奨）

> このリソース自体は FiveM の Mumble native を直接使用していますが、pma-voice を使った近接VC環境での利用を想定しています。

---

## ■ 使い方のコツ

- `/pvlist` で設定済み一覧を確認できます。
- プレイヤーが再接続してIDが変わっても、少し待つと自動で再適用されます。
- 自然に使うなら、`0.3 ~ 0.9` くらいの範囲がおすすめです。

---

## ■ トラブルシューティング

### `Could not resolve identifier for ID XX yet` が出る

プレイヤーマップの更新前です。

- 数秒待つ
- もう一度コマンドを実行する

### 距離によって聞こえ方が不自然に感じる

仕様上、Mumble の volume override は通常の近接VCの距離減衰と少し挙動が異なります。

このリソースは **プレイヤーごとの補正用** として使う前提です。  
近接VC全体を自然にミキシングする用途には向いていません。
